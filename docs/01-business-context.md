# 1. Бизнес-контекст
 
## 1) Бизнес-правила
 
| ID | Бизнес-правило |
|---|---|
| BR-1 | Бронь не осуществляется на срок > 2 ч. |
| BR-2 | Бронирование клиентских комнат осуществляется только офис-менеджером |
| BR-3 | Авторизация в системе производится только по рабочей учетной записи |
 
## 2) Бизнес-требования
 
| ID | Бизнес-требование |
|---|---|
| BRe-1 | Снизить долю неиспользованных броней с 30% до 10% и полностью убрать двойные брони за 3 месяца |
| BRe-2 | Сейчас комнаты бронируют в общей Excel-таблице и в чате. Приложение должно оптимизировать процесс бронирования переговорных комнат. |
| BRe-3 | Сейчас около 30% забронированных комнат стоят пустыми — встречу отменили. Приложение должно после отмены брони освобождать комнату в системе. |
 
## Заказчик
 
Административный директор. Одобряет запуск ПО через 2 месяца с бюджетом 1,5 млн р.
 
## Стейкхолдеры
 
- административный директор
- сотрудники
- офис-менеджер
- ИТ-служба
- служба безопасности
