# Допущения 
* A-1. После запуска системы сотрудники массово перейдут на бронирование через нее и перестанут использовать чат и Excel (Связано с вопросом о текущем процессе бронирования и поведения пользователей)
* А-2. Планшет у двери будет стабильно подключен к корпоративной сети и исправен в рабочее время (Связано с вопросом о поломке планшета)
* А-3. LDAP и корпоративный календарь предоставят необходимые API для интеграции в срок до запуска MVP (Связано с вопросом об интеграции с ИТ-инфраструктурой)

# Риски
* Сотрудники продолжат бронировать комнаты в рабочем чате, игнорируя новую систему.
  * Последствия: Двойные брони сохранятся, доли неиспользованных комнат не снизится, KPI заказчика не будет достигнут.
  * Мера: Запретить бронирование в чате на уровне регламента.
