# 2. Требования по Вигерсу

## Пользовательские требования (UR)
 
| ID | Требование |
|---|---|
| UR-1 | Я, как сотрудник, которому нужна переговорная для обсуждения с командой рабочих вопросов, хочу бронировать переговорную комнату на желаемое время с конкретной вместимостью, чтобы сэкономить время на бронировании. |
| UR-2 | Я, как сотрудник, хочу иметь возможность отменить свою бронь на комнату, чтобы у других сотрудников была возможность забронировать переговорную вместо меня. |
| UR-3 | Я, как офис-менеджер, который отвечает за бронирование клиентских переговорных для встреч с клиентами, хочу бронировать клиентскую переговорную комнату на желаемое время с конкретной вместимостью, чтобы сэкономить время на бронировании. |
| UR-4 | Я, как офис-менеджер, хочу иметь возможность отменять любые брони переговорных, чтобы разрешать проблемы, связанные с бронированиями. |

## Функциональные требования (FR)

| ID | Требование |
|---|---|
| FR-1 | Сотрудник забронировал комнату, если он не подтверждает присутствие за 5 мин до или после начала брони переговорной, то бронирование пользователя отменяется. |
| FR-2 | Сотрудник указывает желаемое время брони при поиске, система предлагает ему только свободные в это время комнаты. |
| FR-3 | Пользователь указывает время брони, превышающее 2 часа, тогда система не даёт осуществить бронь. |
| FR-4 | Сотруднику, не являющемуся офис-менеджером, не предлагаются для брони клиентские комнаты. |
| FR-5 | Система не создаёт бронь, время которой пересекается с временем существующей брони той же переговорной, в том числе при одновременных запросах. |

## Нефункциональные требования (NFR)

| ID | Требование |
|---|---|
| NFR-1 | Сервис бронирования доступен 99% времени в месяц. |
| NFR-2 | Ответ по успешности брони должен приходить в течение 2 с в 90% случаев. |
| NFR-3 | Проверка прав доступа осуществляется на сервере. |
| NFR-4 | Результаты поиска свободных комнат появляются не позже 2 сек. при одновременной работе до 100 пользователей. |

## Ограничения (CON)

| ID | Ограничение |
|---|---|
| CON-1 | Приложение пишется на Java. Мобильные клиенты — iOS и Android. |
| CON-2 | Бюджет — 1,5 млн руб., запуск — через 4 месяца. |

## Внешние интерфейсы (EI)

| ID | Требование |
|---|---|
| EI-1 | Макеты интерфейса должны покрывать версию для ПК (1920px) и для планшетов (≈1280px/2560px). |
| EI-2 | Интерфейс у дверей переговорных работает на планшетах с Android 11+, в браузерах Chrome, Firefox, Safari последних трёх версий. |
