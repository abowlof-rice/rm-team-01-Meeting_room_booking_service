# 3. Пользователи

- Роль: сотрудник

  Цель: провести встречу по работе в свободной переговорной.

  Ключевые действия: поиск, бронирование, подтверждение присутствия по коду, отмена своей брони

  Права доступа: отменяет только свои брони, нет доступа к клиентским броням.

- Роль: офис-менеджер

  Цель: обеспечить бронь переговорных для встреч с клиентами, следить за загрузкой

  Ключвые действия: бронирование клиентских и обычных переговорных, отмена любой брони, получение отчета о загрузке, ведение справочника переговорных

  Права доступа: отменяет любую бронь, видит отчет о загрузке.
